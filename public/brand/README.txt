Dollars & Deductions — vector logo system

All SVG files are true vectors with transparent backgrounds except the presentation backgrounds shown inside master-brand-sheet.svg. Text has been converted to vector outlines so the assets do not depend on installed fonts.

Files:
- icon-full-color.svg
- icon-on-dark.svg             (icon for dark backgrounds: white tile, deep-pine lines, mint-ink fold; same icon as in horizontal-dark.svg)
- icon-single-white.svg
- icon-single-ink.svg
- horizontal-light.svg         (compact lock-up: site header, small placements)
- horizontal-dark.svg
- horizontal-tagline-light.svg (lock-up with tagline; use at >= 600px wide)
- horizontal-tagline-dark.svg
- stacked-light.svg
- stacked-dark.svg
- favicon.svg
- master-brand-sheet.svg       (reference only: uses live fonts, renders with fallbacks on machines without Noto)

Horizontal artboards (with and without tagline): 760 / 120 = 6.33:1.
Stacked artboard: 588 / 256 = 2.30:1 (widened from 520 x 300 so the full wordmark fits, wordmark and tagline centred under the icon).

Tagline lock-ups: "Plain-English tax guides for real business owners", outlined Public Sans 500 (23.2px on the 760 x 120 artboard, +0.01em tracking), fitted edge-to-edge under the wordmark. Wordmark + tagline block raised 5px to centre on the icon. Tagline colour: mint #cfe6da on dark, muted #5a6862 on light.

Palette: pine #0b5d45; deep pine #07352a; mint #cfe6da; mint-ink #a9c9b9; mist #eef4f0; ink #15211c; white #ffffff.
